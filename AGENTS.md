# wanderlust — Project Context & Guidelines

Next.js 16.4.3 + React 19.3 travel-site application. Single package, App Router, npm (only `package-lock.json` committed). No automated test runner or CI pipeline.

## 1. Project Architecture & Tech Stack

- **Framework**: Next.js 16.4.3 (App Router) with Turbopack bundler (`@tailwindcss/turbopack`).
- **React**: React 19.3.0 + React DOM 19.3.0.
- **Compiler**: React Compiler enabled (`babel-plugin-react-compiler` 1.0.0 via `reactCompiler: true`).
- **TypeScript**: TypeScript 5 with `moduleResolution: bundler` and strict mode. Typed routes loaded via `.next/dev/types/**/*.ts`.
- **Styling**: Tailwind CSS v4 (CSS-first, no `tailwind.config.js`). Theme tokens configured in `src/app/globals.css` using OKLCH colors; dark mode variant is `.dark`.
- **UI Components**: Scaffolded via shadcn CLI with `"style": "base-nova"`. Headless primitives are from **`@base-ui/react`** (`^1.9.0`), **not** Radix.
- **Utility / Libraries**: `cn` (published npm package), `lucide-react`, `date-fns`, `react-day-picker`, `embla-carousel-react`, `shiki`, `recharts`, `react-resizable-panels`, `input-otp`, `cmdk`.
- **Typography**: Google Font `Josefin_Sans` loaded in `src/app/layout.tsx`.

## 3. Setup, Run, and Test Commands

- **Install dependencies**: `npm install`
- **Dev server** (Turbopack on `:3000`): `npm run dev`
- **Full build**: `npm run build`
- **Production start**: `npm run start`
- **Linting**: `npm run lint` (Targeted: `npx eslint <paths>`, fix: `npx eslint src/components --fix`)
- **Typechecking**: `npx tsc --noEmit` (On Windows PowerShell: `npx.cmd tsc --noEmit`)
- **UI component scaffolding**: `npx shadcn add <component>` / `npx shadcn list`
- **Testing**: No test suite (Jest/Vitest) is currently installed. Always verify code with `npx.cmd tsc --noEmit` and `npm.cmd run lint`.

## 4. UI Components: base-nova Style (Not Classic shadcn)

`src/components/ui/*` were generated by the shadcn CLI with `"style": "base-nova"`:
- Primitives come from **`@base-ui/react`**, **not** Radix (`@radix-ui/*` is not installed).
- The class helper import is `import { cn } from "cn"` (a published package), **not** `@/lib/utils` — do not rewrite these imports.
- Don't hand-edit UI components directly; regenerate or upgrade through the CLI (`npx shadcn <cmd>`).

## 5. Framework Quirks & Coding Conventions

- **React Compiler**: `next.config.ts` enables `reactCompiler` (`babel-plugin-react-compiler`). Do **not** add manual `useMemo` / `useCallback` unless integrating with legacy external libraries; the compiler manages memoization.
- **Cache Components & Dynamic Data**: `cacheComponents: true` and `partialPrefetching: true` are enabled. Async data in server components must be `await`-ed inside `<Suspense>` boundaries or cached with `use cache`. Unhandled dynamic data triggers a build error.
- **Tailwind v4 CSS-First**: No `tailwind.config` file. Theme tokens live in `src/app/globals.css` (`@theme` / CSS variables). Dark mode uses `.dark` class variant (`@custom-variant dark`).
- **Typed Routes**: `tsconfig.json` includes `.next/dev/types/**/*.ts`; use `LayoutProps<"/">` and generated route types. Path alias `@/*` maps to `./src/*`.
- **Font**: Josefin Sans is the primary custom font set on `html` in `src/app/layout.tsx`.
- **State in Effects**: In React 19 / ESLint 9, avoid synchronous `setState` in `useEffect` bodies (`react-hooks/set-state-in-effect`).
